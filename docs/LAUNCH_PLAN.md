# Launch plan

This is a future sharing plan, not a record of promotion already performed. The goal is to reach people who have a real Windows Codex diagnostic problem without manufacturing activity or overstating the project.

## Before sharing

1. Publish a tested public release with a reproducible Quick Start.
2. Confirm CI, issue templates, private vulnerability reporting, and the disclaimer work on GitHub.
3. Run the released archive on at least one clean Windows 11 environment and, when available, one Windows 10 environment.
4. Prepare one actual redacted console example and a short limitations list.

## Relevant channels

- GitHub repository, Releases, and carefully labeled topics
- OpenAI Developer Community discussions where Windows Codex troubleshooting is already relevant
- PowerShell community spaces for PowerShell-specific review
- Windows developer communities for AppX/MSIX, PATH, WSL, and shell diagnostics
- Relevant Reddit communities only when a post directly answers an existing class of problems and follows local rules
- Developer social platforms used by the maintainer, with a factual release note rather than mass outreach

## Honest launch message outline

- The problem: Windows command discovery is not the same as command execution.
- What v0.1.0 does: local read-only diagnostics plus redacted reports.
- What it does not do: no automatic repair, telemetry, elevation, or official OpenAI affiliation.
- How to try it: three Quick Start commands.
- What feedback is useful: reproducible `UNKNOWN` cases, localized error text, and missing safe checks.

## Boundaries

Do not buy or exchange stars, use alternate accounts, create fake issues/PRs/contributors, claim unverified adoption, mass-message strangers, post in unrelated repositories, or promise to fix every Codex problem. Track only metrics GitHub produces from real activity, and treat stars as an outcome rather than the product goal.
